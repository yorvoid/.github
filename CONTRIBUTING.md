# Contributing to YorvoID

Thanks for helping to improve YorvoID!

All of YorvoID is developed in [yorvoid/yorvoid](https://github.com/yorvoid/yorvoid). The package repositories, such as `yorvoid/core` or `yorvoid/symfony`, are read-only copies of its `packages/` directories, made on every push: changes made in them would be lost, and pull requests there are closed automatically.

Please open issues and pull requests in [yorvoid/yorvoid](https://github.com/yorvoid/yorvoid), and follow [its contributing guide](https://github.com/yorvoid/yorvoid/blob/main/CONTRIBUTING.md). For security issues, follow [the security policy](SECURITY.md) instead.

Everyone taking part follows our [code of conduct](CODE_OF_CONDUCT.md).
