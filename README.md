# yorvoid/.github

The YorvoID organization's defaults on GitHub:

- [`profile/README.md`](profile/README.md) is the organization's page, at [github.com/yorvoid](https://github.com/yorvoid).
- The community health files ([code of conduct](CODE_OF_CONDUCT.md), [contributing](CONTRIBUTING.md), [security policy](SECURITY.md), [support](SUPPORT.md), [issue](ISSUE_TEMPLATE/config.yml) and [pull request](pull_request_template.md) templates) apply to every repository of the organization that has none of its own: the read-only package repositories. They send people to [yorvoid/yorvoid](https://github.com/yorvoid/yorvoid), which has its own.
