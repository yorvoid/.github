# Getting help

- **Documentation:** start with [the README](https://github.com/yorvoid/yorvoid#readme) and the guides in [docs/](https://github.com/yorvoid/yorvoid/tree/main/docs).
- **Bugs:** if something doesn't work as documented, [open an issue in yorvoid/yorvoid](https://github.com/yorvoid/yorvoid/issues/new/choose) with the steps to reproduce it, whichever package it's in.
- **Feature requests:** open an issue in yorvoid/yorvoid describing the problem you want to solve.
- **Security issues:** follow [the security policy](SECURITY.md); don't open a public issue.

YorvoID is in early development and maintained by a small team, so answers can take a few days.
